# 모델 자산

소스와 작은 개인화 변환 파일만 Git에 포함한다. 학습 데이터, PT/ONNX/NCNN/TFLite 가중치, 가상환경, 실제 사용자 기록은 포함하지 않는다.
기존 `sky-eye-integrated-20261101.tar.gz`의 `models/`를 프로젝트의 `models/`로 복사하면 파이용 가중치와 해시 메타데이터를 사용할 수 있다. `models/ASSETS.json`은 배포 압축에 들어 있는 모델 파일의 경로와 SHA-256이다. 압축 SHA-256은 `669e509ca69a5eaf899ccb35b483cc7ad7a4722ef10d39c15a22d73af4b4334f`이다.
다른 사람에게 전달할 때는 소스 저장소와 배포 압축을 함께 전달한다. 학습 재현용 원본 데이터는 각 출처의 이용 조건에 따라 별도로 준비한다.
